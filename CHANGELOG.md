# Changelog

## [0.2.0] - 2026-11-16

### Added
- Interactive alert rule builder, category breakdown card, and RFC3339 time-range filters in the web dashboard UI.
- Time-range query and rule-validation tests in `internal/api/server_test.go`.
- Comprehensive README with Mermaid diagram, CLI/HTTP documentation, and known limitations.

## [0.1.0] - 2026-11-16

### Added
- Multi-format parser supporting JSON lines, Nginx/Apache Combined access logs, Syslog RFC3164, and timestamped logs.
- Real-time file tailing, error classification, and z-score error-rate anomaly detection.
- Sliding-window alert rules with webhook dispatch, gzip log archiving, REST API, and web dashboard.
